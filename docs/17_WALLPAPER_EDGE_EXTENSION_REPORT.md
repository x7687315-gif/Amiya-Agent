## 一、改动内容

### 1. 中央大圆形 = 舰桥光晕（已删除）

那是 Phase 1 之前的"舰桥基调"设计（560×560 圆形 BRIDGE_ACCENT 呼吸光晕），纯色背景
时代的氛围元素；壁纸背景下就是一个突兀的大圆。已连同 `_breathe` 呼吸任务一并移除
（陪伴计时保留）。

### 2. 壁纸左置 + 主色延伸（按用户方案）

**烘焙层（构建时，一次性）**——六套皮肤的 `background.jpg` 全部重制为统一
**2560×1600 画布**：
- 提取壁纸**右边缘条带**（6%）的占比主色作为延伸色——贴左布局下右缘即接缝，
  取边缘色使过渡无缝（比全图平均色更准；sakura/warm 右缘为白，延伸即白）；
- 壁纸按高度适配**贴左侧**（超宽图按宽度封顶），右侧余量用主色铺满；
- 主色同时写入 `skin.json` 的 `dominant_color` 字段。

各皮肤提取结果：pale `#A29DA0`、sakura `#FFFFFF`、starry `#013685`、
sunset `#4D2E2C`、warm `#FFFFFF`、winter `#E9E9E9`。

**运行时层**——背景改为三层 Stack：
```
[壁纸右缘主色铺底（dominant_color，兜底 c.BG）] → [壁纸 BoxFit.COVER] → [浅色遮罩（可读性）]
```
统一 16:10 画布 + COVER 的行为：常规窗口≈显示全部壁纸+右侧延伸；超宽窗口裁掉的
只是右侧延伸色区——任何窗口形状下背景都连续自然。**每张壁纸大小不一的问题由
统一画布天然解决**（原图已存 git 历史，可随时重烘）。

### 3. 数据模型

`Skin` 新增 `dominant_color: Optional[str]`，`SkinManager` 从 skin.json 加载；
缺失时运行时回退 `c.BG`。
